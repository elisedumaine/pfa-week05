## Midterm Pitch — Interactive World Builder
# The tool in one sentence. 
 I will build an Unreal Engine GUI called Interactive World Builder that lets an artist create a small, customizable natural game world with a playable character.
# The chore it ends.
 Normally, creating a simple level means manually placing terrain, trees, rocks, lighting, and a player character one element at a time. This can take several hours each time I want to test a new environment. My tool will create and adjust a basic world much faster through a single interface.
# The UI.
 The GUI will include:
   - A world-theme menu: forest, mountain, beach, or meadow
   - Sliders for terrain size, number of trees, number of rocks, grass density, and lighting intensity
   - Color controls for the sky, ground, and lighting
   - A field for the world name
   - Buttons for Generate World, Preview, Save Preset, Load Preset, Reset, and Delete World
   - A checkbox to add a playable character and enable movement
# Why it's advanced. What makes it more than one script? 
This is more than one script because the tool generates several connected parts of a playable environment. It will save settings as presets, preview changes before replacing the current world, work with different environment themes, and include reset/delete options to avoid mistakes. The generated world will include a character that can move through the environment.
# The three weeks. Oct 13, by Oct 20, and by Oct 26.
 By October 13, I will have a working GUI and a button that creates a simple terrain with a character.
   By October 20, the tool will generate trees, rocks, grass, lighting, and different world themes through sliders and menus.
   By October 26, I will add presets, preview/reset features, improve the visual quality, and test the complete interactive world.
# The smallest version that still counts.
 If the more advanced features do not work, I will show a GUI that generates one natural environment with adjustable terrain size, trees, rocks, lighting, and a movable player character.
# The riskiest part.
  The riskiest part is making the generated environment look natural while also allowing the GUI to update or replace it correctly without creating duplicate objects or breaking the playable character.
